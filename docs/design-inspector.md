# Design Inspector

ReviewShell 오른쪽 자 아이콘으로 디자인 인스펙터를 엽니다. 기본 제공 도구이며
QA 작성 권한, `sourceRoot`, 디자인 기준 해상도 설정이 없어도 사용할 수 있습니다.
기존 상단 Ruler 버튼과 화면 가장자리 자는 표시하지 않습니다.

## 사용 방법

- `Shift+Q`: 현재 페이지와 리뷰 페이지 전환. 일반 페이지에는 `mountFigmaDevOverlay`가 설치되어 있어야 합니다.
- `Shift+1`: 패널 열기/닫기. 한글 키보드에서도 동작합니다.
- 다른 레일 패널과 동일하게 레일 버튼이나 토글 단축키로 닫습니다. 별도 닫기 버튼과 `Escape` 닫기는 제공하지 않습니다. 입력창의 문자 입력은 단축키로 가로채지 않습니다.
- 요소 선택: iframe의 DOM을 호버·클릭하여 크기, 폰트, 색상, 계산된 CSS를 확인합니다.
- 거리 측정: 요소 선택 후 Alt/Option+호버하거나 거리 측정 버튼을 사용합니다.
- 사이트 조작: 일반 클릭, 입력, 스크롤, 링크 이동을 허용합니다.
- 테마: Settings의 Dark / Light / System을 따릅니다. 테마를 바꿔도 선택·측정 상태와 검사 대상 페이지는 유지됩니다.

검사 모드에서는 QA 선택, 기존 Option 소스 선택, Figma 이미지 드래그가 같은
제스처를 소비하지 않도록 잠급니다. `E`, `A` 등으로 QA 작성 모드에
진입하면 인스펙터를 닫고 QA 패널로 전환합니다. 패널을 닫으면 잠금을 해제합니다.
패널 전환만으로 대상 iframe을 새로 생성하거나 스크롤을 맨 위로 돌리지 않습니다.

## 통합 범위

`DesignInspectorPanelContainer`는 기존 ReviewShell iframe을 `frame`으로 전달하고,
필요할 때만 엔진을 불러옵니다. 별도 미리보기 iframe, Figma 업로더, Studio API는
만들지 않습니다. Figma 이미지는 기존 ReviewShell의 이미지 관리 기능을 그대로 사용합니다.

검사 대상은 현재 ReviewShell과 동일 출처인 iframe입니다. 교차 출처 페이지는
브라우저 보안 정책상 DOM을 읽을 수 없으며, 별도 postMessage 브리지는 제공하지 않습니다.

소스 힌트가 있는 요소의 소스 열기는 기존 `sourceInspector`/`sourceRoot` 설정과
편집기 어댑터를 사용합니다. CSS 표시값은 브라우저 계산값이며 원본 CSS 파일과
줄 번호를 의미하지 않습니다. 입력한 폼 값, 인증 토큰 또는 검사 데이터를 서버로
전송하거나 저장하는 기능은 추가하지 않습니다.

`ruler` prop은 기존 QA 측정 설정 호환성을 위해 남아 있지만, 별도의 상단 자 UI를
다시 표시하지는 않습니다.
