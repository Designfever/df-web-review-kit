# Release Notes: 0.13.0

Review Kit을 사용하면서 발견한 개선사항을 DF Sheet에 바로 등록할 수 있는
사이드 패널을 추가합니다.

## 추가

- 개선사항 패널에서 제목, 유형, 관련 영역, 상세 내용을 입력할 수 있습니다.
- 이미지를 최대 5장 첨부할 수 있으며 기존 DF Sheet 첨부 업로드 경로를
  재사용합니다.
- 현재 Review Kit 화면 주소를 등록 내용에 자동으로 포함합니다.
- DF Sheet 세션 어댑터가 `/api/review/improvements`로 개선사항을 등록하고
  생성 결과 링크를 반환합니다.
- 기능을 제공하지 않는 커스텀 어댑터에서는 개선사항 버튼을 표시하지 않습니다.

## 연동 조건

DF Sheet 서버에 `/api/review/improvements` 등록 API가 배포되어 있어야 합니다.
알림 전송과 최종 저장은 해당 DF Sheet API가 담당합니다.

## 검증

- Vitest 61개 파일의 테스트 318개를 통과했습니다.
- TypeScript 타입 검사를 통과했습니다.
- 라이브러리와 CLI 빌드, npm 패키지 구성 검사를 통과했습니다.
