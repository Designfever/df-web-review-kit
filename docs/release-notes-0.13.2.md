# Release Notes: 0.13.2

DF Sheet에 연결된 프로젝트가 마지막으로 선택한 리뷰 페이지를 새로고침
이후에도 유지할 수 있도록 공통 세션 API를 추가합니다.

## 개선

- 페이지 선택값을 DF Sheet 프로젝트와 로그인 사용자별로 분리해 저장합니다.
- `resolveSelectedPageId()`로 저장된 페이지가 현재 접근 가능한 페이지인지
  검증한 뒤 자동 진입할 수 있습니다.
- `rememberSelectedPageId()`로 페이지 전환 시 선택값을 즉시 갱신할 수
  있습니다.
- 삭제됐거나 접근 권한이 사라진 페이지는 저장값에서 자동으로 제거합니다.
- 로그아웃해도 페이지 선택값은 유지하되, 인증 토큰은 기존처럼 짧은
  `sessionStorage` 세션에만 보관합니다.

## 적용

자체 페이지 선택 화면을 가진 프로젝트는 `session.listPages()` 결과를
두 API에 전달합니다. 프로젝트별로 별도의 `localStorage` 코드를 작성할
필요가 없습니다.

## 검증

- 프로젝트와 사용자별 선택값 저장과 새로고침 복원을 검증했습니다.
- 접근할 수 없어진 페이지의 저장값 제거와 다른 프로젝트 페이지 저장
  차단을 검증했습니다.
- 기존 df-login 세션, 페이지 선택, Figma 이미지 인증 경로의 회귀 테스트를
  유지합니다.
