# Release Notes: 0.13.3

DF Sheet 인증 실패 후 페이지 전환 시 QA 패널이 계속 로딩 중으로 남는 문제를 수정합니다.

- QA 또는 Figma 요청이 HTTP 401을 반환하면 거부된 세션 캐시를 제거합니다.
- 이전 요청의 늦은 응답이 새로운 로그인 세션을 삭제하지 않도록 보호합니다.
- QA 초기 로딩 실패 시 로딩 상태를 종료하고 오류 메시지를 표시합니다.
- 전체 리뷰 페이지를 새로고침하면 다시 로그인할 수 있습니다. 자동 토큰 갱신은 포함하지 않습니다.
- 기존 페이지 선택 유지 및 QA 상태 동기화 기능을 유지합니다.

검증: 세션 캐시 제거, 새 세션 보호, 페이지 초기화 실패와 재시도에 대한 회귀 테스트를 추가했습니다.
