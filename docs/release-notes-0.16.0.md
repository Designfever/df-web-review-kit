# Release Notes: 0.16.0

3000px 이상의 화면을 리뷰할 수 있도록 iframe 표시 배율을 조절하고,
이슈 스크린샷에 iframe viewport 전체 맥락을 남깁니다.

## Iframe 확대·축소 (#1487)

- 기본 Fit 모드에서 리뷰 영역에 맞춰 iframe 전체를 표시합니다.
- 헤더 오른쪽 grid 버튼 앞의 드롭다운에서 10–200% 배율을 선택할 수 있습니다.
- 드롭다운은 기존 viewport select와 높이, 여백, 배경, 화살표 스타일을 공유합니다.
- 배율을 변경해도 iframe 내부 해상도와 responsive breakpoint는 유지합니다.
- 기본 Ultra Wide 프리셋에 3840×2160을 추가합니다. 사용자 지정 `presets`는
  기존 설정을 유지하므로 필요한 wide 해상도를 직접 추가해야 합니다.
- 이슈 마커, 소스 선택 highlight와 ruler의 좌표 변환에 배율을 반영합니다.
- 브라우저 캡처 영역이 바깥 스크롤 영역에 가려지면 잘못된 캡처를 차단합니다.

## 이슈 스크린샷 (#1486)

- DOM/Area 이슈의 Capture 버튼과 저장 시 자동 캡처 모두 선택 영역 대신
  현재 iframe viewport 전체를 캡처합니다. 스크롤 페이지 전체를 캡처하지 않습니다.
- 이슈 마커와 선택 윤곽선을 이미지에 포함해 위치와 주변 레이아웃을 함께 확인합니다.
- SVG fallback에도 viewport 캡처 메타데이터를 기록합니다.
- 기존에 저장된 cropped 스크린샷은 변경하지 않습니다.

## 검증

- unit test 409개, typecheck와 package build 통과.
- 로컬 fixture에서 3840×2160 viewport, Fit/50% 표시와 배율별 마커 위치 확인.
- DOM 수동 캡처와 Area 자동 캡처가 3840×2160 WebP로 저장되는지 확인.
- 저장된 이미지의 전체 맥락과 선택 윤곽선을 확인하고 reload 후 첨부 유지 확인.

## 캡처 제약

- 실제 Chrome 탭 공유 기반 캡처는 실브라우저에서 검증하지 않았습니다.
  해당 경로의 전체 출력 크기와 highlight 합성은 단위 테스트로 검증했습니다.
- 브라우저 캡처는 화면에 보이는 픽셀을 사용합니다. 축소한 화면을 원래 크기로
  출력해도 세부 픽셀은 복원되지 않습니다. 전체 브라우저 캡처에는 Fit을 사용하고,
  target 해상도로 렌더링하려면 html2canvas 방식을 사용합니다.
