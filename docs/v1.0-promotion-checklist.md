# v1.0 promotion checklist

v0.10 keeps the installer deliberately small. Do not promote the workflow to v1.0 until the framework-neutral boundary and real-host flows are proven.

## Packed artifact

- [ ] The packed CLI installs the exact package version with npm, pnpm, and Yarn.
- [x] Init dry-run is read-only and init creates only `df.ts`.
- [x] Next.js and Vite hosts receive version-pinned framework guide URLs.
- [x] The CLI never writes `/review`, router, Vite, provider, or custom adapter code.
- [x] Legacy automatic route migration is blocked and remains read-only.
- [x] Removed custom/provider init options fail without changing the host.

Synthetic evidence: [Packed Installation E2E Matrix](pack-install-e2e.md).

## Real hosts

- [ ] `ikaos-content-studio-v2026` completes df-login, page selection, Figma overlay, QA submit, and source opening.
- [ ] One Vite host completes the same flow without legacy review tokens or Figma env values.
- [ ] One Next.js or Vue host completes its host-owned `/review` recipe.
- [ ] Route teardown/remount works through real client navigation.
- [ ] Legacy Lexus remains working during the transition.

## Contract freeze

- [ ] `InitConfig` schema v2 (`projectId`, `projectName`) is frozen.
- [ ] `df.ts` ownership and `REVIEW_PROJECT_ID` meaning are frozen.
- [x] df-login PKCE/short-session behavior is defined for 0.10.
- [x] df-sheet adapter and Figma proxy client APIs are defined for 0.10.
- [ ] Framework guide paths and minimum verification steps are frozen.
- [ ] Doctor diagnostic codes and severities are frozen.

## Safety and release

- [x] Project ID is documented as public identification, not authorization.
- [x] Browser code receives no permanent df-sheet token or raw Figma token.
- [x] Custom Jira, Mantis, Trac, FTP, database, and Figma bridges stay host-owned.
- [ ] Dependency and packed-file review is complete.
- [x] v0.10 release notes list the breaking installer changes and manual route boundary.
- [ ] Package version, tag, npm dist-tag, and version-pinned guide URLs are verified.
