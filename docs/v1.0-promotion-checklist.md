# v1.0 Easy Install Promotion Checklist

v0.9 remains experimental until every required item below is complete and reviewed. Record evidence links or commit SHAs beside each item during release preparation.

## Packed Artifact

- [x] `npm pack` artifact installs into clean React + Vite JavaScript and TypeScript fixtures.
- [x] Clean fixtures pass init, doctor, TypeScript checking, production build, and idempotent rerun.
- [x] A generic custom review provider profile passes install, doctor, typecheck, build, and rerun.
- [x] A recognized 0.8-style fixture passes preview, backup, migration, doctor, typecheck, build, and rerun.
- [x] Conflict and unsupported-customization fixtures return exit code 1 without changing host files.
- [ ] npm, pnpm, and Yarn host lockfile/install behavior is independently verified where those package managers are available.

Synthetic evidence: [Packed Installation E2E Matrix](pack-install-e2e.md).

## Real Hosts

- [ ] First existing React + Vite host completes previewed migration and remains buildable.
- [ ] Second existing React + Vite host completes previewed migration and remains buildable.
- [ ] Both hosts verify the generated `/review/` route in a browser.
- [ ] Both hosts verify rollback from the migration backup or version control.

## Contract Freeze

- [ ] CLI commands, option names, prompts, and exit codes are reviewed and declared stable.
- [ ] `InitConfig` schema version and generated file ownership rules are reviewed and declared stable.
- [ ] Provider profile schema and capability composition are reviewed and declared stable.
- [ ] Doctor diagnostic codes, severities, JSON shape, and fix hints are reviewed and declared stable.
- [ ] Migration eligibility, backup manifest, rollback policy, and idempotency guarantees are reviewed.
- [ ] Breaking changes from v0.9 are documented with an upgrade path.

## Safety

- [x] Dry-run and default doctor operations are read-only.
- [x] Stale plans and user-owned generated-path conflicts block all writes.
- [x] Unsupported host customization remains a blocker rather than an automatic rewrite.
- [x] Generated source, diagnostics, logs, `.env.example`, and CLI arguments do not carry secret values.
- [ ] Final dependency and supply-chain review is complete.
- [ ] Final public package inspection confirms no private endpoints, organization-only integrations, credentials, or operator rules.

## Documentation and Release

- [x] Quick Start covers a clean host and an existing host.
- [x] Init, doctor, migration preview/apply, backup, rollback, custom profile, security, and conflict behavior are documented.
- [x] Packed documentation commands are executable against the package artifact.
- [ ] Release notes list every intentional v0.9-to-v1.0 contract change.
- [ ] Stable support matrix and known limitations are published.
- [ ] Package version, npm dist-tag, README links, and release notes are correct in the packed artifact.
